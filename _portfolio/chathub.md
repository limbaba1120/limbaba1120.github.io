## 한 줄 소개

개발자들이 온라인에서 커피챗 상대를 찾고, 클라우드 기반 실시간 화상채팅으로 대화할 수 있는 서비스입니다. 기획·개발·운영을 팀원들과 협업하며 진행했습니다.


## 주요 기여

<section class="pf-contrib" markdown="1">

### 실시간 화상 채팅

사용자 간 음성·영상 통신과 화상회의 관리 기능을 구현했습니다.

- Amazon Chime SDK를 활용해 실시간 오디오·비디오 송수신 구현
- Meetings API로 회의 생성·종료, 참가자 등록 및 참여 토큰 발급 처리

### GitHub 소셜 로그인

- Spring Security와 OAuth 2.0 클라이언트를 활용해 GitHub 계정 기반 회원가입·로그인 구현

</section>

## 느낀 점

<section class="pf-reflection" markdown="1">

프론트엔드 팀원과 처음으로 협업한 프로젝트입니다. Spring Security와 WebRTC 같은 기술을 다루는 데 있어 처음에는 많은 어려움을 느꼈습니다.

백엔드 개발 경험이 부족해서 기술을 깊이 이해하는 데 한계를 느꼈지만, 강의를 듣고 영어로 작성된 공식 문서를 읽으며 Chime SDK를 학습했고, 기술에 대한 자신감이 생겼습니다.

단순히 강의만 보며 따라 하던 과거와는 다르게, 프로젝트에서 기술을 사용해보고 문제를 해결했던 경험이 개발 실력을 빠르게 향상시켜주었고, 개발에 대한 즐거움이 생겼습니다.

앞으로는 다른 프로젝트를 하면서 다양한 사람들과 협업을 더 많이 해야겠다고 생각했고, 새로운 기술을 배우면서 더 깊이 이해하고 빠르게 성장하는 개발자가 되고 싶다고 느꼈습니다.

</section>
